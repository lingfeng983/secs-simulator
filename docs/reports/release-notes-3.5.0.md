# 3.5.0 发布说明

发布日期：2026-11-23
类型：质量版（修跳转错位、统一配置草稿、首屏减半；无配置格式变更、无破坏性 API 变更）

3.4.0 把配置区改成了「按页保存、按段生效」，这一轮做的是**收尾**：把那次改版留下的
错位与死代码清掉，让「全量配置」和结构化子页终于共用同一份草稿，再把首屏体积砍掉一半。
界面上大部分页面长得和之前一样，改动集中在「点了会去错地方」「两页互相把保存顶成 409」
「明明没人用的按钮还在那儿」这三类问题上。

## 一、命令面板：三处跳转不再错位

| 命令 | 以前 | 现在 |
|---|---|---|
| `{设备} · 配置区` | 落到**运行区**（复用了「打开设备」的跳转） | 落到配置区概览 |
| `查看 SVID {n}` | 落到「事件与报告」页 | 落到「变量配置」页 |
| `填入 CEID {n}` | 把值写进一个**没有任何界面在读**的全局状态 | 命令整条删除 |

前两条是最容易被当成「页面坏了」的那种错位：按文案点进来，看到的却是另一页。
第三条删掉的理由是它做不到文案承诺的事——事件编排改版后 `backend.ceid` 已经没有任何
消费方，点了等于什么都没发生。要找 CEID 去「事件与报告」页，那里才是它的家。

## 二、「全量配置」与结构化子页共用一份草稿

以前两边各管一份草稿、各拿一个修改时间做并发校验（If-Match）：在原文页改了内容，
切到「变量配置」页看不到；两边先后保存，后保存的一方只会拿到 409，还得手动「重新载入」。

现在它们读写的都是同一个草稿仓库、同一条按段基线：

- 在原文页改完切到子页，改动就在那里；
- 子页保存只推进**本页那几段**的基线，别页未保存的改动仍然如实标成脏（页签小圆点照旧）；
- 原文页保存是整份写回，所有段的基线一起推进；
- 两边不会再互相把保存顶成 409——真正会撞 409 的只剩「另一个窗口/进程改了磁盘上的文件」，
  那才是这条保护本来要拦的情况。

顺带统一了两处细节：原文页保存成功后不再在页面里重复写一句「已保存 …」（右下角提示已经说了），
「重新载入」的确认框改用与结构化页同一套文案（「放弃未保存的改动？」）。

## 三、批量同步配置：失败要说清是哪一台、为什么

「批量同步」以前只报成功台数：8 台里 3 台没成功，界面照样说「已同步 8 台」，
用户得一台台去翻才知道漏了谁。现在：

- 逐台收集失败原因（校验不通过的原因、保存失败的 HTTP 状态、异常信息），
  汇总成一条提示，**并且弹框不关**——留在原处才能就地重试；
- 只有真的成功了至少一台才报成功；
- 端口分配改成「从起始端口开始找第一个空闲端口」，把工作台里各设备的现有端口和各设备
  配置里的端口都算作占用。以前按序号顺推，会撞上还没同步的那几台正在用的端口。

## 四、旧深链不再落到一个不存在的页

2.x 的 `#/device/{id}/{page}` 深链会做一次一次性映射。映射表里不认识的子页名，
兜底值指向的 `catalog` 页在 3.0 就下线了——从旧书签进来会看到一个空页面。
现在兜底落到运行区首页，并补了一条单测钉住这个行为。

## 五、性能：首屏从 562 kB 降到 264 kB

| 项 | 以前 | 现在 |
|---|---|---|
| 首屏 JS（minify 前） | 562 kB / gzip 190 kB | **264 kB / gzip 87 kB** |
| 目录 + 事件计划轮询 | 所有页面都是 2 秒 | 设备页 2 秒，其余页面 20 秒 |
| 表单草稿写入 localStorage | 每敲一个键写一次 | 300 ms 防抖，页面要走了再补一次 |

- **路由级分包**：8 个页面各自成块，主机侧面板、模板编辑器、曲线图表都等到真的打开那一页
  才下载；外壳（顶栏 / 导航 / 页签）先出来，内容区留白一下。
- **轮询按页面需要**：目录与事件计划只有设备页在读，其它页面降到 20 秒一次。
  没有完全停掉，是因为命令面板的「查看 SVID」也从目录里取条目——停掉会让用户在
  工作台按 Ctrl+K 找不到 SVID。
- **输入缓存**：只存与初始值不同的字段（改回原值就删掉条目），并把 JSON 原文编辑器
  排除在缓存之外——它本来就有自己的草稿仓库，再存一份既白占空间，回填时还会和草稿打架。

## 六、内部收敛

- 配置页的公共外壳不再提供顶部动作组（「重新载入 / 校验 / 保存」）：三个按钮在结构化页
  早就不该有（保存入口在页面自己手里），留着只是让人误以为没保存。现在「重新载入 / 校验」
  只属于「全量配置」页。
- 删掉上一版图表的残骸：`uplot` 依赖与它的 CSS import、`chartMode` 偏好（界面上已经没有
  入口，值还一直躺在 localStorage 里）。
- 删掉会话维度的旧主机模拟端点封装（`openHostSim` / `closeHostSim` / `sendHostSml`）——
  主机模拟早已迁到独立页，这三个方法没有任何调用方。

## 七、测试

新增两个 hook 测试文件（`useConfigDraft` 13 项、`useEventStream` 12 项），
覆盖按段基线推进、三种 409 守卫、结构段延迟生效、票据重取、暂停缓冲上限、重连补拉。
为此引入 `jsdom`（仅 devDependency）和一个三十行的 hook 挂载器——项目原有测试全是
静态渲染，碰不到 effect。

## 八、兼容性与升级

- **配置文档格式不变**，数据库 schema 不变，API 无破坏性变更。
- 新增一个 devDependency（`jsdom`），只影响开发/测试，不进产物。
- 版本号统一 3.5.0（9 个 pom、两个 `package.json`/lock、`tauri.conf.json`、
  `Cargo.toml`/`Cargo.lock`、`BuildInfo.VERSION`）。
- 直接覆盖安装即可；旧版本留下的 `chartMode` 偏好不会再被读取，无需手工清理。
