## 已知边界（本次不动）

- 前端仍是全局 CSS 层叠，拆文件不产生作用域隔离；如需隔离应另立 ADR 引入 CSS Modules。
- `features/` 按"页面/面板/图表/编辑器"分组，不按业务域（设备/主机/模板）细拆——
  当前跨页复用较多，按域拆会制造更多跨目录导入。
- `secs-api-http` 的 handler 粒度、`secs-app` 内部服务对象的进一步拆分未在本次范围内。
