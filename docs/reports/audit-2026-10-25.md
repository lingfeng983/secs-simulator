## 二、欠缺项

### 功能欠缺

1. **报文/审计无按会话与方向的真实过滤**:`client.messages(session, direction, limit)` 的参数三处调用全部传 `('', '', …)`(useDataCommands.ts:58,90,112),后端的过滤能力对用户不可达;audit 只有 limit,无按 action/actor/会话过滤。
2. **分页缺位**:messages(limit≤5000)与 audit(limit≤1000)都无 cursor/offset,翻旧账只能拉满;超出 5000 条内存环形缓冲的旧报文永久丢失(工具定位下可接受,但界面应明示保留窗口)。
3. **配置保存无版本控制**:PUT /configs/{name} 无 If-Match/lastModified 前置条件,两个窗口同时编辑后保存会静默互相覆盖;无配置历史/diff 端点。
4. **压测/采集结果不可导出**:SendPanel:301-307 与 BurstCard:157-166 的统计只是 `<pre>`,恰恰是最该留档的数据。
5. **LiveEventList 无历史回看与导出**:硬编码 50 条(LiveEventList.tsx:24),无"载入历史"入口;ConsolePanel 日志不可排序。
6. **审计仅内存态**:后端不可用时 503,重启全丢(HttpApiServer.java:1965)。

### 状态与反馈欠缺

7. **CollectorCard 无空态**:无数据时直接不渲染图表区(CollectorCard.tsx:255),无"尚未采集到数据"引导。
8. **HostSimPanel 连接动作无 busy**:onOpen(70-88 行)慢时会重复点击。
9. **AuditPanel 注释与实现不符**:注释声称非管理员有说明分支,代码没有(AuditPanel.tsx:7-13 vs 55)。
10. **危险操作确认策略不齐**:批量关闭有 `window.confirm`(SessionsPanel:319),单台关闭没有;`window.confirm` 与系统 Modal 风格割裂,应统一为 ConfirmModal。

### 契约层欠缺(openapi ↔ 实现)

11. **openapi 漏声明 3 个在用端点**:`POST /config-preview`、`GET/POST/DELETE /sessions/{id}/host-sim`、`POST /sessions/{id}/host-sim/send`(前端都在用)。
12. **PUT /sessions/{id}/host-sim/collector 是死声明**:后端只收 POST,openapi 主方法 405。
13. **错误包络两处偏离**:`{valid,problems}`(config 校验路径)与 `{ok:true,name}`(config 创建)不按 `{ok,error}` 体系;openapi 对 PUT /configs 400/422 连 schema 都没写。
14. **前端错误解析四种写法并存**:`json()` 只 throw 原始文本(api.ts:432-436),不解析 `{ok,error}`——后端精心设计的错误码到 UI 只是 JSON 串;collector/bulk/saveConfig 又各自手动解析。应统一:json() 解析包络、抛带 code 的 ApiError。
15. **schema 漂移**:前端 CollectorState 含 `svids`(api.ts:232),openapi 没有。
16. 小项:openapi `/log-level` 用的 `system` tag 未在顶部声明。

## 三、页面排版与设计问题

### 真 Bug(用户可见)

1. **三处分段控件激活态失效**:`.segment.active`(App.css:503)是唯一激活样式,但 WorkbenchPage:94、DevicePage:99、BurstCard:86 的按钮 `className={active?'active':''}` **漏了 `segment` 类**——工作台状态过滤、设备页 9 子页导航、压测类型切换当前都没有选中高亮(截图已证实呈现为散落按钮而非分段控件)。修法:这三处补 `segment` 类,或把激活样式改成 `.segmented button.active`。
2. **v6 段引用未定义变量**:`var(--border)`(2495,2517,2570,2582,2585,2589)、`var(--surface)`(2497,2519,2574)、`var(--text-muted)`(2500,2528,2537,2558,2596,2601)从未定义且无 fallback → 整条声明被丢弃,卡片边框/背景/灰字实际处于"碰巧能看但失控"状态。修法:在 :root 增补这三个别名(指向 --line/--bg-soft/--muted)。
3. **`.toolbar` 无定义但 7 处使用**(WorkbenchPage:81、BurstCard:80,118,148、CollectorCard:231 等)→ 过滤行无 flex/gap,元素裸排。补一条 `.toolbar{display:flex;gap:8px;align-items:center;flex-wrap:wrap}`。

### 一致性问题

4. **深色主题对比度硬伤**:`.badge.tone-ok{color:#1a7f37}`、`.tone-warn{color:#b0700f}`(2598-2599)写死浅色主题色,深色卡片上对比度不足;select 箭头 data-URI 固定色(348)、遮罩色(1865)同理。
5. **密度切换实际只影响表格行高**:`--row-pad` 唯一消费点是 .data-table(1132),按钮/表单/卡片/栈间距全不响应,与设置项文案"行高与间距"不符。
6. **工具栏布局两派**:有 Panel actions 工具栏的(Console/Messages/Preview/Send/HostSim/Config)vs 操作按钮塞 body 的(Alarms/Audit/Catalog/Events/Sessions)。
7. **主按钮使用不一**:同类主操作有的 `.primary` 有的没有;禁用依据不一(有的按 activeSession,工具卡按传入 sessionId)。
8. **孤儿样式可删**:`.two-col`(2565)、`.ov-page/.ov-kpis/.ov-grid/.ov-card*`(1611-1663)、`.quick-actions`(1664)、`.mini-feed` 12 个选择器(1671-1751)、`.panel-head-lite`(1644)。
9. **Focus 可访问性**:命令面板输入框 `.palette-input` 显式去掉 outline 且 focus 无替代指示(1917-1923)。
10. 其他:`.align-center`(1212)无引用;`.collapsible-title`/`.diff-text` 类名无样式定义;`@media 1100px` 两个独立块;`.spark` 列模板四处定义。
