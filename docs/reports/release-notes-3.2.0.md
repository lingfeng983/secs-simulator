# 3.2.0 发布说明

发布日期：2026-11-17
类型：功能版（界面交互升级为主；一个可选 API 字段，无破坏性变更、无数据库 schema 变更）

3.1.0 之后围绕两条主线：一是把界面上"常驻占版面的说明文字"全部收进标题悬浮气泡，
并把设备连接页改成一行一项的统一表单网格；二是把「一次开一批设备」收进新建设备弹框、
给新建主机加「创建后立即连接」开关。升级即生效，无需迁移。

## 界面：说明文字悬浮化（默认不占版面）

规则一句话：**描述性的语句只在悬浮到它归属的标题上时出现**；空态提示、错误与校验信息、
状态说明仍然直接可见——它们是"当前发生了什么"，不是"这个东西是什么"。

| 位置 | 3.1.0 | 3.2.0 |
|---|---|---|
| 表单字段说明 | 标题下一行小字常驻 | 悬浮/键盘聚焦在标题上出气泡（虚线下划线提示"这里有说明"） |
| 小节 / 弹框标题的整段说明 | 说明段落常驻在标题下 | 悬浮标题弹出（气泡在标题下方，不会被弹框头裁掉） |
| 设备连接页 | 说明占左半行，行高不齐 | 一行一个配置项、标题列对齐、控件列左边缘对齐（超时/Trace 容量同网格） |
| 无标题面板的说明 | 段落常驻 | 挂到最相关控件的原生 title（＋新建按钮 / SML 输入框 / 「载入更早」等）或页签悬浮说明 |

- 实现收口在两个组件：`FieldLabel`（字段级）与 `HintTitle`（小节/弹框标题级），
  `Modal` / `Collapsible` 直接传 `hint`；后续新界面不再写常驻说明段。
- 空态、错误、状态提示保持原样可见（如"还没有分段…"、"配置原文不是合法 JSON…"）。

## 新建设备弹框：批量模式

弹框顶部「批量新建」开关，一次按同一份设备模板开一批：

| 项 | 规则 |
|---|---|
| 数量 | 1–100 |
| 会话 id | 前缀 + 序号（dev-1、dev-2…），不能含空白 / 斜杠 / 引号 |
| 端口 / Device ID | 起始值逐台递增，越界与已有占用在建前预检提示 |
| 配置本体 | 一批共用一份基础配置（`前缀-模板id-base.json`），连接标识只在运行期覆盖，不写回配置文件 |
| 区域 | 整批归入所选区域 |
| 启动 | 批量恒为创建即启动 |

- 同「前缀 + 模板」的批次复用同一份基础配置，不同模板互不覆盖。
- 顺手删掉了清单里那个早已打不开的独立「批量新建设备」弹框（其入口在早前清理中丢失）。

## 新建主机：立即连接开关

- 「新建主机」「按模板新建主机」弹框新增「立即连接」开关（默认勾选，保持创建即建链的习惯）。
- API：`POST /api/v2/hosts` 增加可选 `connect`（缺省 `true`）；`false` 时只建实例、停在断开态，
  与重启后装回内存的实例同态，之后在清单 / 详情页点「连接」。
- 旧客户端不带该字段时行为不变。

## 其它

- 「批量同步配置」弹框说明并入标题气泡；端到端用例同步到新文案、连接页新结构与
  「新建主机后先跳详情再回清单」的时序。
- 已废弃的 UI 设计 skill 文档删除；「说明悬浮」的要求落成组件模式
  （`FieldLabel` / `HintTitle`），由代码与用例约束。

## 升级步骤

- **桌面版**：直接覆盖安装 `SECS Simulator_3.2.0_x64-setup.exe`（工作目录与两个 SQLite 库向前兼容）。
- **服务端（Linux/JVM）**：解压覆盖 `secs-sim-server-3.2.0-linux.zip`，重启进程即可。
- 3.1.0 → 3.2.0 无数据库 schema 变更、也没有配置迁移；`connect` 字段可选，
  老客户端与脚本不受影响。
